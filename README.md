# Chat Hub

Slack-inspired collaboration platform built with

- Angular
- Signals
- NgRx Signal Store
- Supabase
- PostgreSQL
- Nx

## Requirements

- Node
- pnpm

## Install

pnpm install

## Start

pnpm start

## Test

pnpm test

## Build

pnpm build


## Local Supabase

This project uses the Supabase CLI for local development.

### Prerequisites

- Docker Desktop
- Node.js
- pnpm

### Start

```bash
pnpm supabase start
```

### Stop

```bash
pnpm supabase stop
```

### Status

```bash
pnpm supabase status
```

The first startup downloads the required Docker images and may take several minutes.
